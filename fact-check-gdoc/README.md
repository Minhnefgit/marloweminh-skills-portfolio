# Google Docs Fact-Checking

[Back to the skill catalogue](../README.md)

**Category:** Content creation & quality

## Purpose

Resolve factual concerns raised in Google Docs comments using live website evidence.

## Main procedure

1. Read the document and comments.
2. locate authoritative website sources.
3. assess each flagged claim.
4. prepare justified corrections.

## Expected output

A corrected Markdown draft with highlighted changes and separate fact-check notes.
