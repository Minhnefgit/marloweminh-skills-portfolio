# Team Daily Time-Log Report

[Back to the skill catalogue](../README.md)

**Category:** Reporting & planning

## Purpose

Convert a team member’s Zoho time logs into a readable daily report.

## Main procedure

1. Resolve the person and date.
2. collect time logs.
3. categorise work.
4. clean notes.
5. reconcile totals.
6. render the report.

## Expected output

Markdown and IM-branded HTML reports with work summaries and time totals.
