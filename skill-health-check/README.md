# Skill Health Check

[Back to the skill catalogue](../README.md)

**Category:** Workflow tooling

## Purpose

Assess whether a skill’s workflow and dependencies are ready to use.

## Main procedure

1. Locate the skill.
2. identify workflow stages and required tools.
3. check dependency availability.
4. summarise failures and operational limits.

## Expected output

A health report showing workflow stages, tool requirements, dependency status, and blockers.

## Portfolio scope

This is a high-level capability summary, not an installable skill or an execution guide. Operational instructions, prompts, scripts, templates, client files, and client-file links are not published here.
