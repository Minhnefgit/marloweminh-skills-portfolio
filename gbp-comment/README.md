# Google Business Profile Review Replies

[Back to the skill catalogue](../README.md)

**Category:** Delivery & task management

## Purpose

Publish supplied review replies against the correct live customer reviews.

## Main procedure

1. Read the authorised response queue.
2. match review identifiers.
3. enter the exact approved response.
4. verify and record the result.

## Expected output

Verified published replies and a completion report listing unresolved or skipped reviews.
