# SEO Keyword Research

[Back to the skill catalogue](../README.md)

**Category:** SEO research & audits

## Purpose

Build a prioritised keyword strategy tied to relevant website pages.

## Main procedure

1. Analyse the website.
2. agree seeds.
3. expand keyword evidence.
4. filter and quality-check relevance.
5. map and prioritise.
6. deliver after review.

## Expected output

Keyword research, page mappings, priority outputs, and approved Google Sheets delivery.
