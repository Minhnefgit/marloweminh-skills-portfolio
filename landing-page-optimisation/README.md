# Audit-Led Landing Page Optimisation

[Back to the skill catalogue](../README.md)

**Category:** Content creation & quality

## Purpose

Turn accepted landing-page audit findings into focused content improvements.

## Main procedure

1. Select the accepted page audit.
2. use its keyword and reader-answer gaps as the brief.
3. preserve useful copy.
4. revise and verify.
5. request review.

## Expected output

Optimised page drafts linked to the accepted audit brief, without automatic publishing.

## Portfolio scope

This is a high-level capability summary, not an installable skill or an execution guide. Operational instructions, prompts, scripts, templates, client files, and client-file links are not published here.
