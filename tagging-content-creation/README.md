# Collection SEO Content Creation

[Back to the skill catalogue](../README.md)

**Category:** Shopify & ecommerce

## Purpose

Write brand-aligned SEO fields for Shopify tag-group collections.

## Main procedure

1. Read the source tag groups and brand guidance.
2. inspect representative products.
3. draft collection copy and metadata.
4. validate the updated rows.

## Expected output

An updated tagging CSV containing titles, meta descriptions, slugs, collection content, and collection URLs.
