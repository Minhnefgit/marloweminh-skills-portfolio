# Private HTML Report Deployment

[Back to the skill catalogue](../README.md)

**Category:** Reporting & planning

## Purpose

Deliver local HTML reports through an access-protected hosting workflow.

## Main procedure

1. Validate the report and destination.
2. stage the approved HTML.
3. deploy through the private publishing route.
4. verify access behaviour.

## Expected output

A private hosted report URL with deployment and access-verification results.
