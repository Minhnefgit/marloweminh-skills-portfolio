# Safe Session Cleanup

[Back to the skill catalogue](../README.md)

**Category:** Workflow tooling

## Purpose

Identify and clean up stale agent and browser sessions while protecting active work.

## Main procedure

1. Inspect eligible sessions.
2. distinguish protected, ambiguous, and stale processes.
3. stop only permitted targets.
4. inspect the resulting state.

## Expected output

Before-and-after cleanup records and explicit stopped, protected, skipped, and surviving-session results.
