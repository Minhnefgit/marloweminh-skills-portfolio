# Blog Topic Suggestion

[Back to the skill catalogue](../README.md)

**Category:** Content creation & quality

## Purpose

Identify useful blog opportunities that support existing landing pages.

## Main procedure

1. Review website coverage and keyword context.
2. research topic opportunities.
3. review relevance.
4. validate topic-to-page alignment.

## Expected output

A reviewed topic plan in CSV or Google Sheets with supporting landing-page relationships.

## Portfolio scope

This is a high-level capability summary, not an installable skill or an execution guide. Operational instructions, prompts, scripts, templates, client files, and client-file links are not published here.
