# Shopify Automated Collection Preparation

[Back to the skill catalogue](../README.md)

**Category:** Shopify & ecommerce

## Purpose

Prepare Shopify automated collections from approved workbook or table rows.

## Main procedure

1. Build the source queue.
2. confirm row and template scope.
3. populate collection fields and tag rules.
4. verify each prepared collection.

## Expected output

Unsaved collection drafts ready for manual review, with a completion and exception report.
