# Website Image Audit

[Back to the skill catalogue](../README.md)

**Category:** SEO research & audits

## Purpose

Assess live website image delivery without modifying the website.

## Main procedure

1. Agree a page sample.
2. inspect image delivery and platform behaviour.
3. measure assets.
4. evaluate optimisation options.
5. review the report.

## Expected output

A self-contained HTML report separating measured findings from projected savings.
