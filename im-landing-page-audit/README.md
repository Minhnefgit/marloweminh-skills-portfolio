# Landing Page Content Audit

[Back to the skill catalogue](../README.md)

**Category:** SEO research & audits

## Purpose

Assess a landing page against search intent and relevant competing pages.

## Main procedure

1. Confirm the target page and keyword.
2. approve research scope.
3. preserve source evidence.
4. compare reader needs and content gaps.
5. review the report.

## Expected output

A scored HTML audit per completed page, with evidence-backed content gaps and recommendations.
