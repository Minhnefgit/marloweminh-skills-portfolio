# Multi-Market Rank Tracking

[Back to the skill catalogue](../README.md)

**Category:** SEO research & audits

## Purpose

Track Visibuild search rankings across agreed keywords and markets.

## Main procedure

1. Confirm the keyword and market scope.
2. collect SERP evidence within approved limits.
3. validate results.
4. compare runs.
5. publish approved reporting updates.

## Expected output

Validated ranking results and reporting-sheet updates for the selected AU, UK, and US checks.
