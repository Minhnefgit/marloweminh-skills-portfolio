# Content Optimisation

[Back to the skill catalogue](../README.md)

**Category:** Content creation & quality

## Purpose

Improve existing page content using performance, brand, and search evidence.

## Main procedure

1. Prioritise eligible pages.
2. establish the live baseline and brand voice.
3. research keywords and competitors.
4. revise and quality-check content.

## Expected output

Optimised page drafts with baseline and research context for review and delivery.
