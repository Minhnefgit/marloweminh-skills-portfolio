# Website Image Optimisation

[Back to the skill catalogue](../README.md)

**Category:** Website implementation

## Purpose

Improve image delivery and technical SEO within an existing website codebase.

## Main procedure

1. Audit current assets.
2. choose suitable conversions and responsive variants.
3. update image references and metadata.
4. verify desktop and mobile rendering.

## Expected output

Optimised image assets, updated website references, and implementation verification for review.
