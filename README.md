## What is public — and what stays private

Every published file is a README written for this portfolio. The repository contains no executable skills, full operational instructions, prompts, scripts, reference packs, templates, client deliverables, client source files, transcripts, credentials, or links to client files. Client names may appear to describe a workflow's context; their inclusion does not imply endorsement.

The underlying implementations are maintained separately with restricted access. This repository has its own clean history; it is not a fork or a mirror of the implementation collection.

## About the collection

This catalogue reflects accumulated practice and adaptation, including workflows originating in shared team work. It does not claim that Minh solely authored every underlying component. IM, client, contributor, and third-party rights remain with their respective rights holders. Descriptions explain intended capabilities, not independently measured performance results.

## Use and sharing

The public summaries can be viewed and technically cloned like any public GitHub repository. Cloning this repository does not provide the private skill implementations. No open-source licence or permission to reuse underlying IM, client, or third-party material is granted by this portfolio. Any reuse requiring permission should be cleared with the relevant rights holder.

## Portfolio updates

Publish only newly written, high-level README summaries. Before adding or changing a summary, confirm publication permission and remove client-file content, client-file links, internal identifiers, credentials, and operational implementation details. Do not upload source skill packages or synchronise the private implementation tree.
