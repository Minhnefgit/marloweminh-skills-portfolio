# Keyword Filtering Quality Gate

[Back to the skill catalogue](../README.md)

**Category:** SEO research & audits

## Purpose

Independently audit keyword filtering before mapping or delivery.

## Main procedure

1. Compare source and filtered keywords.
2. check intent, exclusions, duplicates, and coverage.
3. identify false keeps and removals.
4. recommend corrections.

## Expected output

A pass/fail quality report with evidence-backed filtering issues and targeted correction guidance.
