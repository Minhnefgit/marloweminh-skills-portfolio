# Publishing Handover

[Back to the skill catalogue](../README.md)

**Category:** Delivery & task management

## Purpose

Hand client-approved content to the publishing owner.

## Main procedure

1. Identify approved subtasks.
2. preview the target assignments.
3. apply authorised handover updates.
4. verify status, comments, and time records.

## Expected output

A verified publishing handover report with completed changes and outstanding issues.
