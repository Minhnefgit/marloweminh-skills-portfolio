# Content SEO Optimisation Lite

[Back to the skill catalogue](../README.md)

**Category:** Content creation & quality

## Purpose

Optimise explicitly supplied page URLs without a page-discovery stage.

## Main procedure

1. Resolve brand guidance.
2. extract the current page.
3. optimise and independently verify the draft.
4. fact-check.
5. stop for manual review.

## Expected output

Local optimised Markdown drafts for approval before any separately authorised upload.

This is a high-level capability summary, not an installable skill or an execution guide. Operational instructions, prompts, scripts, templates, client files, and client-file links are not published here.
