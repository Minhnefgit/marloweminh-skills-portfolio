# Shopify Product Tagging

[Back to the skill catalogue](../README.md)

**Category:** Shopify & ecommerce

## Purpose

Apply scoped product-tag changes using approved source rows.

## Main procedure

1. Read the tag rules and product queue.
2. verify each live product.
3. skip redirected or draft products.
4. enter permitted tags.
5. verify changes.

## Expected output

Unsaved product-tag changes ready for review, plus a processed and skipped-item report.
