# Location Page Uniqueness

[Back to the skill catalogue](../README.md)

**Category:** Content creation & quality

## Purpose

Make location pages meaningfully distinct while preserving their page structure.

## Main procedure

1. Compare related city pages.
2. identify duplicated passages and wrong-location details.
3. revise with supported local distinctions.
4. check language and layout constraints.

## Expected output

Distinct location-page drafts with checks for duplication, city accuracy, spacing, grammar, and Australian spelling.
