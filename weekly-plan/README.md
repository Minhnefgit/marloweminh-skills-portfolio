# Weekly Work Planning

[Back to the skill catalogue](../README.md)

**Category:** Reporting & planning

## Purpose

Turn monthly task data into a practical weekly delivery plan.

## Main procedure

1. Classify actionable tasks.
2. preserve task order and related groups.
3. schedule business-day work.
4. validate the plan.
5. publish authorised updates.

## Expected output

A scheduled task CSV and formatted Google Sheet, with optional authorised due-date synchronisation.
