# Verified Task Status and Handover

[Back to the skill catalogue](../README.md)

**Category:** Delivery & task management

## Purpose

Apply consistent, verified Zoho subtask handovers and time logging.

## Main procedure

1. Discover eligible subtasks.
2. confirm the requested scope.
3. update ownership and handover comments.
4. log authorised time.
5. verify resulting records.

## Expected output

A per-subtask handover summary showing verified changes and any failed or pending actions.
