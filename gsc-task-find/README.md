# GSC Opportunity Task Discovery

[Back to the skill catalogue](../README.md)

**Category:** SEO research & audits

## Purpose

Find high-impression pages that are eligible for content optimisation.

## Main procedure

1. Review Search Console performance.
2. check recent optimisation evidence.
3. rank eligible pages.
4. create and verify subtasks after approval.

## Expected output

A prioritised page shortlist and, when authorised, verified Zoho optimisation subtasks.
