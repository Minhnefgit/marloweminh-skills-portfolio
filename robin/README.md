# Robin Daily Report

[Back to the skill catalogue](../README.md)

**Category:** Reporting & planning

## Purpose

Present daily work in a Robin/Sway-themed reporting experience.

## Main procedure

1. Collect the day’s time logs.
2. organise work and totals.
3. render Markdown and themed HTML.
4. include usage summaries only when requested.

## Expected output

A Markdown report and self-contained themed HTML report, with optional aggregated AI usage.
