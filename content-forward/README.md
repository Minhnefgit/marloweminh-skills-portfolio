# Content Approval Handover

[Back to the skill catalogue](../README.md)

**Category:** Delivery & task management

## Purpose

Move reviewed content into the client-approval workflow.

## Main procedure

1. Identify eligible reviewed subtasks.
2. preview the handover.
3. apply authorised assignment and status changes.
4. verify comments and time records.

## Expected output

Verified handover results identifying completed changes and any unresolved items.
