# Ahrefs Technical SEO Audit

[Back to the skill catalogue](../README.md)

**Category:** SEO research & audits

## Purpose

Turn supplied Ahrefs exports into an evidence-led technical SEO review.

## Main procedure

1. Review export coverage.
2. classify supported issues.
3. organise findings by issue type.
4. validate the deliverable.

## Expected output

A technical SEO audit CSV bundle covering errors, broken links, metadata, indexing, and other supported findings.
