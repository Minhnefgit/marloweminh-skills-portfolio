# Schema Optimisation

[Back to the skill catalogue](../README.md)

**Category:** Structured data

## Purpose

Generate or improve Schema.org JSON-LD using supported page and entity facts.

## Main procedure

1. Extract existing schema and visible content.
2. reconcile entity information.
3. optimise markup.
4. validate.
5. report findings for review.

## Expected output

Page baselines, optimised JSON-LD and page JSON files, plus a validation report.
