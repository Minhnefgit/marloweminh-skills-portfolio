# Final Content Review

[Back to the skill catalogue](../README.md)

**Category:** Content creation & quality

## Purpose

Review Google Docs content for factual accuracy, SEO quality, and client-profile alignment.

## Main procedure

1. Read the draft and client guidance.
2. verify claims against official sources.
3. assess language and intent.
4. attach actionable review comments.

## Expected output

Anchored Google Docs review comments where supported, plus a written review report.
