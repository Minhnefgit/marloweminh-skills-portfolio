# Structured Data Delivery Pipeline

[Back to the skill catalogue](../README.md)

**Category:** Structured data

## Purpose

Coordinate schema work from page selection through stakeholder delivery.

## Main procedure

1. Identify the brand and pages.
2. optimise structured data.
3. prepare review artefacts.
4. deliver approved files.
5. update tracking and task records.

## Expected output

Page-level schema deliverables, review artefacts, delivery records, and verified tracking updates.
