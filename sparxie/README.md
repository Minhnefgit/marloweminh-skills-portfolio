# Sparxie Daily Report

[Back to the skill catalogue](../README.md)

**Category:** Reporting & planning

## Purpose

Present daily work in a Sparxie/Planarcadia-themed reporting experience.

## Main procedure

1. Collect the day’s time logs.
2. organise task summaries and totals.
3. render Markdown and themed HTML.
4. optionally summarise AI usage.

## Expected output

A Markdown report and interactive self-contained HTML report, with optional aggregated AI usage.
