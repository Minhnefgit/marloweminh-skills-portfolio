# Tone-of-Voice Verification

[Back to the skill catalogue](../README.md)

**Category:** Content creation & quality

## Purpose

Independently check whether a draft matches documented brand voice.

## Main procedure

1. Resolve the brand reference.
2. read the draft independently.
3. score alignment.
4. identify deviations.
5. provide an evidence-based verdict.

## Expected output

A tone-of-voice report with dimension scores, strengths, deviations, and a review verdict.
